# پریزنتیشن سمینار نسخهٔ وب همراه محصل

۲۰ اسلاید دری، اندازهٔ ۱۶:۹، زمان پیشنهادی ۱۵ تا ۲۰ دقیقه.

- PowerPoint: قابل ویرایش، همراه یادداشت هر اسلاید در Notes.
- PDF: مناسب نمایش با چیدمان ثابت و بدون نیاز به نصب فونت.
- Presenter-Notes.fa.md: متن پیشنهادی ارائه و راهنمای دمو.
- بستهٔ ZIP: همهٔ فایل‌ها همراه فونت Vazirmatn و مجوز آن؛ پیش از بازکردن PowerPoint فونت‌ها را نصب کنید.

نام ارائه‌کننده، مضمون و استاد را می‌توانید به اسلاید نخست اضافه کنید. تصاویر واقعی رابط نسخهٔ وب با داده‌های ساختگی تهیه شده‌اند. امکانات اختصاصی دسکتاپ در این ارائه معرفی نشده‌اند.

منابع: فایل‌های README.fa.md، package.json، src/server.js، src/domain.js، src/store.js، src/backups.js و public/app.js در پوشهٔ web همین مخزن.
