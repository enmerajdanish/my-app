## نسخهٔ جدید دسکتاپ ۱.۲

[دانلود به‌روزرسانی دسکتاپ](https://github.com/enmerajdanish/my-app/releases/tag/desktop-v1.2.0) · [راهنمای جدید دسکتاپ](desktop/README.fa.md)

حاضری قلمی، ورود نتایج Excel، تصدیق‌نامهٔ Word، پشتو و روشن/تاریک اضافه شده‌اند. نسخهٔ وب همان نسخهٔ قبلی است.

در دسکتاپ ۱.۲، حاضری و تصدیق‌نامه با نمونه‌های اصلی تطبیق داده شده‌اند؛ شمارهٔ ثبت در Word برای نوشتن دستی خالی است.
