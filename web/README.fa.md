# نسخهٔ مستقل وب

پیش‌نیاز: Node.js 24، npm و Docker برای MongoDB Replica Set محلی.

```sh
npm ci
docker compose up -d --wait
npm run setup
npm start
```

آدرس `http://127.0.0.1:3000` را باز کنید. کد تولیدشده با setup را در فورم اولین مدیر وارد کنید و حساب دلخواه بسازید. فایل .env حاوی کلیدهای خصوصی است و نباید منتشر شود.

در ویندوز start-web.cmd همین مراحل را اجرا می‌کند. برای استفاده از MongoDB موجود، MONGODB_URI و MONGODB_DB را در .env تعیین کنید؛ replica set برای تراکنش ضروری است. برنامه پیش‌فرض فقط روی همین دستگاه در دسترس است.

ابتدا استاد بسازید، سپس کورس ایجاد و داخل کورس ثبت‌نام/Excel، حاضری، گزارش و تصدیق‌نامه را مدیریت کنید. نمونه‌های اصلی در samples هستند. تاریخ‌های ورودی استاندارد میلادی و نمایش تاریخ‌ها شمسی است. نسخهٔ وب به پوشهٔ desktop وابسته نیست.

پشتیبان دستی و بازیابی از تنظیمات؛ پشتیبان خودکار در backups هنگام بازبودن سرور، هر ساعت با نگهداری آخرین ۳۰ نسخه. دیتابیس MongoDB با توقف برنامه باقی می‌ماند.

آزمون: npm test؛ برای آزمون دیتابیس MongoDB در Linux/macOS: TEST_MONGO=1 npm test؛ در PowerShell: $env:TEST_MONGO='1'; npm test.
