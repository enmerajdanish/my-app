# نسخهٔ مستقل دسکتاپ

برای استفادهٔ معمول فایل نصب Hamrah-Mohasel-Setup-1.0.0.exe را اجرا کنید؛ Node.js و MongoDB لازم نیست. نصب‌کننده میانبر دسکتاپ و منوی Start می‌سازد.

در اولین اجرا کد راه‌اندازی نمایش داده می‌شود. آن را در صفحه وارد کنید و حساب مدیر دلخواه با رمز حداقل ۱۰ حرف بسازید. کد در config.json پوشهٔ اطلاعات برنامه هم موجود است.

برای اجرای سورس با Node.js 24:

```sh
npm ci
npm start
```

شروع با start-desktop.cmd نیز ممکن است. نصب اولیهٔ وابستگی‌های سورس اینترنت می‌خواهد؛ اجرای روزمره و نسخهٔ نصب‌شده آفلاین است.

ساخت مجدد نصب‌کننده: npm run build:win؛ خروجی در dist قرار می‌گیرد. آزمون‌های SQLite: npm test.

این نسخه SQLite داخلی دارد و به MongoDB یا پوشهٔ web متصل نمی‌شود. دیتابیس، کلیدها و پشتیبان‌ها در userData برنامه قرار دارند؛ در ویندوز معمولاً %APPDATA%\kunduz-course-desktop. حذف برنامه این داده‌ها را حذف نمی‌کند. انتقال به دستگاه دیگر را از تنظیمات با پشتیبان/بازیابی JSON انجام دهید.

برای چاپ تصدیق‌نامه، پس از تکمیل کورس و صدور، دکمهٔ چاپ/PDF را انتخاب کنید. چاپ خالی حاضری فقط سه ستون شماره، اسم و ولد دارد. اطلاعات نمونه خودکار وارد نمی‌شوند؛ فایل Excel را در کورس انتخابی وارد کنید.

بسته بدون امضای دیجیتال است. اجرای Electron و گردش آفلاین در Linux بررسی شده؛ نصب exe روی ویندوز در محیط ساخت آزموده نشده است.
